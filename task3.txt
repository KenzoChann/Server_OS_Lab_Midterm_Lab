Task 3 explanation:
For the GET request, the data was sent in the URL, after the "?".
The script showed it as "Query string: course=192-442&week=4".
For the POST request, the data was sent in the request body.
The script showed it as "POST body: name=student&id=123",
and the "Query string:" line was empty.
In the access log, the GET line has the full URL with the data:
/cgi-bin/echo.sh?course=192-442&week=4
The POST line only has the path: /cgi-bin/echo.sh
This matters because Apache saves the full URL in plain text,
so anyone who can read the log can see GET data.
POST data is not written in the access log.
A password sent by GET would end up in many places,
for example the browser history and the server access log.
(It can also be in the URL bar and in bookmarks.)
